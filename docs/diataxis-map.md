# Diátaxis documentation map

This sample documentation set uses the Diátaxis framework to separate documentation by user need.

## Tutorial

Tutorials help new users learn by completing a guided task.

Sample:

- [Quick start: Run your first inference request](tutorials/quickstart-run-first-inference.md)

Why it is a tutorial:

- It assumes the user is new to the API.
- It provides a successful first path.
- It focuses on learning by doing rather than complete reference coverage.

## How-to guide

How-to guides help users complete a specific goal.

Sample:

- [Create a GPU inference job](how-to/create-gpu-inference-job.md)

Why it is a how-to guide:

- It starts from a practical user goal.
- It provides steps and commands.
- It includes troubleshooting guidance related to the task.

## Explanation

Explanation topics help users understand concepts and system behavior.

Sample:

- [GPU inference jobs](concepts/gpu-inference-jobs.md)

Why it is explanation:

- It describes how the job lifecycle works.
- It compares synchronous and asynchronous inference.
- It gives context for technical decisions.

## Reference

Reference topics provide accurate, structured information.

Samples:

- [Inference API reference](reference/inference-api.md)
- [Error handling](reference/error-handling.md)
- [OpenAPI sample](../openapi/astra-inference-openapi.yaml)

Why they are reference:

- They organize fields, endpoints, statuses, and error codes.
- They are designed for lookup rather than guided learning.
- They prioritize precision and consistency.
